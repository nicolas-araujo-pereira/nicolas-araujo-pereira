O projeto começou como uma forma de praticar os fundamentos do desenvolvimento web e evoluiu para uma aplicação com diferentes funcionalidades, incluindo:

- Criação de tarefas

- Filtros por status
- Contadores de tarefas
- Tema claro e escuro
- Sistema simples de login e cadastro
